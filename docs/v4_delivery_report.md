## 1. 里程碑 P1：前线与作战计划系统

### 1.1 核心机制落地
* **智能填线算法**：
  * 实现 `findFrontierHexes`，自动根据己方边界与交战国接触面求解前线格。
  * 采用均匀分布防超堆叠分配算法（每格严格 $\le 6$ 师上限），实现 100% 战线覆盖率。
* **作战计划与进攻箭头**：
  * 支持划定进攻箭头（指向目标突破格）与后撤防线（Fallback Line）。
  * 每日计划加成积累（+2%/天，基础上限 30%，每有效进攻箭头 +10%，封顶 50%）。
  * 执行进攻计划时，参与师按日平滑消耗 5% 计划槽转化为实战攻击加成 $(1 + \text{planning})$。
* **微操惩罚机制（Hard Constraint C13–C15）**：
  * 当玩家对受编入计划的部队下达右键手动指令时，触发微操惩罚：**该师即刻脱离计划并扣减全军 5% 计划槽**。
* **战术卡系统与将领四维能力**：
  * 引入攻（attack）、防（defense）、策（planning）、后（tactics）四维将领技能树。
  * 战斗交火时按将领战术值触发战术卡：包抄（flank，软攻 +15%）、强攻（assault）、弹性防御（elastic_def）、纵深防御（depth_def）、突袭（shock）与迟滞（delay）。
  * 军长指挥上限 $\le 24$ 师，超编触发递进惩罚（$-25\%$ 至 $-50\%$）。军长可消耗 50 CP 晋升为战区元帅（Marshal）。
* **UI 与交互**：
  * 实现专职集团军面板 `panelArmy.js`。
  * 地图层绘制前线高亮光晕、红色进攻箭头及虚线后撤线。

## 2. 里程碑 P2：原版核心指标与内政外交

### 2.1 核心指标与世界紧张度
* **世界紧张度（World Tension, 0–100%）**：
  * 实现 `tension.js`。
  * 剧本 A 历史事件链严密注入紧张度：开战 (+25%)、英法参战 (+10%)、苏军进军波兰 (+15%)、华沙陷落 (+10%)。
  * 和平期每日自然衰减 0.1%。
  * 门槛限制：民主国家制造战争借口需紧张度 $\ge 50\%$，保证独立随时可用；法西斯/共产主义无门槛。
* **指挥点数（Command Power, CP）**：
  * 设定上限 200 点，每日自然增长，受将领与法案加成；用于将领晋升（50 CP）、紧急战役决断。
* **内政与外交综合控制台**：
  * HUD 顶部实时指示：装备、政治点、指挥点、陆战经验、世界紧张度（鼠标悬停查看历史因果）。
  * 模态框 4 选项卡体系：
    1. **统帅部**：查看领袖、将领四维、晋升元帅、前线指派。
    2. **政治与经济法案**：民用经济、部分动员、战时经济、总动员（各 150 PP）。
    3. **征兵动员法案**：志愿兵役制（1.5%）、有限征兵（2.5%）、广泛征兵（5.0%）、强制服役令（10.0%）。
    4. **内阁三系顾问**：3 政治顾问、3 军事总长、3 经济军需专家（各 150 PP）。
    5. **外交行动**：制造战争借口（50 PP）、保障独立（25 PP）、派遣志愿军（30 PP，紧张度 $\ge 30\%$）、战时租借法案（20 PP，紧张度 $\ge 50\%$ 或同盟国）。

## 3. 里程碑 P3：师设计器与装备生产链

### 3.1 师编制设计器
* **5×5 战斗营方阵 + 5 支援连槽位**：
  * 实现 `template.js`。
  * 5 种战斗营：步兵营、炮兵营、装甲营、摩托化营、骑兵营。
  * 5 种支援连（不占战斗宽度）：工兵连、支援火炮、侦察连、野战医院、后勤连。
  * 4 套经典预设编制：
    1. **标准步兵师**（9 步 1 工）：18 战宽，54 软攻，50 组织度。
    2. **七步二炮师**（7 步 2 炮 + 工 + 炮）：**严格 20 战宽，107 软攻**。
    3. **经典装甲师**（4 坦 4 摩 + 工 + 炮）：16 战宽，95 软攻，81 硬攻，45% 装甲率。
    4. **快速骑兵旅**（4 骑 + 侦）：8 战宽，26 软攻。
  * 调整槽位经验花费：每修改/替换一个槽位精确消耗 **5 陆军经验 (Army XP)**。
  * **换装与缺编减员**：当前国家装备库存不足时换装，部队兵力耐久按缺编比例折减（$\text{fillRate} < 1.0$），随军工厂排产每日自动补员。

### 3.2 军工厂 5 条装备生产链
* 涵盖 5 种标准装备：`inf_eq`（步兵武器）、`art_eq`（火炮）、`tank_eq`（坦克）、`truck_eq`（卡车）、`sup_eq`（支援装备）。
* 单条产线军工厂上限 15 家。
* 每日产量公式：$\text{daily} = \text{factories} \times 5.0 \times \text{efficiency} / \text{cost}$。
* 效率成长公式：$\Delta\text{eff} = 0.001 \times \text{cap}^2 / \text{current}$。
* **转产效率保留**：生产线切换装备类型时保留 **50%** 当前累积效率（而非直接归零或重置至 10%）。
